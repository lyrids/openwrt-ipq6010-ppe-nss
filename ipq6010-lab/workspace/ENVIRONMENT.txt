All development and builds run inside this Linux VM. The macOS side is
used only to initiate SSH and transfer existing evidence.

Directories:
  src/openwrt-main  upstream OpenWrt checkout
  downloads         shared source download cache
  ccache            compiler cache (20 GiB limit)
  artifacts         exported images and build manifests
  logs              build/check logs
  evidence          router inventory and host/source manifests
  bin               workspace helper scripts

Enter environment:
  cd ~/projects/openwrt-dev
  . ./env.sh
  cd src/openwrt-main

Default parallelism: 8 jobs (BUILD_JOBS), chosen conservatively for 15 GiB RAM.
The OpenWrt build creates its own target cross-toolchain. Host build tools
are ARM64; no distribution cross compiler or multilib packages are required
for the initial environment.

Host dependencies can be reapplied with bin/install-host-deps.
No global shell startup files or global Git configuration were changed.
Source/feed pins and validation results are stored under evidence.

No router flashing or reboot is part of this environment setup.

Feed installation policy:
  Initially installing every package exposed Kconfig recursion in unrelated
  Qt5, luci-app-fwknopd, and squeezelite packages. Source files were not patched.
  Generated links were reset and only luci, iperf3 and their feed dependencies
  were installed. This prepares available package definitions; it does not
  automatically enable LuCI or iperf3 in the image configuration.
  Metadata warnings for uninstalled optional packages remain in defconfig.log;
  no Kconfig recursion/errors remain. Install additional package definitions
  deliberately with ./scripts/feeds install <package> as the image evolves.

Build configuration:
  artifacts/ax6600-main.config contains the full generated configuration.
  artifacts/ax6600-main.config.seed contains its compact diffconfig.
  artifacts/state-main contains the source/feed/configuration snapshot.
  bin/snapshot-build-state can refresh these records after intentional changes.
