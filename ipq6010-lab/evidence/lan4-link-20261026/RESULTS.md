# LAN4 investigation context

Initial m4m endpoint disappeared and LAN4 flapped repeatedly. Temporary EEE disable did not establish stable connectivity; no EEE fix claimed. Original EEE setting was restored before RAM reboot. User confirmed m4m failed to boot. Authorized WRT32X replacement then linked and sustained LAN4 management successfully. This evidence does not diagnose a DUT PHY defect. No persistent EEE configuration was added.
